# Nyaya-Knowledge-Validation-Framework
The Nyāya Knowledge Validation Framework is developed as a web-based application using modern computer science concepts. It combines web technologies with a predefined knowledge base to validate user-entered statements.
The project is built using HTML, CSS, JavaScript, and Bootstrap 5. HTML is used to create the structure of the web pages, CSS and Bootstrap 5 are used to design a responsive and attractive user interface, and JavaScript is used to implement the validation logic and make the application interactive.
The system stores a collection of predefined statements in a JavaScript knowledge base (database.js). When the user enters a statement, JavaScript compares the input with the stored data. If a matching statement is found, the system displays the corresponding Nyāya validation details, confidence score, and verdict (VALID, PARTIALLY VALID, or INVALID). If no matching statement is found, the system informs the user that the statement is not available in the knowledge base.
The application also uses the browser's Local Storage to save validation history, allowing users to view their previous searches even after refreshing the page. Bootstrap components such as cards, buttons, forms, and progress bars are used to create a responsive and user-friendly interface.
This project demonstrates the application of fundamental computer science concepts such as web development, data storage, searching, event handling, user interface design, and client-side programming to build a practical knowledge validation system.
